## 1. CNN (Convolutional Neural Network) - "ดวงตาของ AI"

ตอนแรกที่เรียนเรื่อง Neural Network ก็คิดว่ามันแค่มองตัวเลขแล้วทำนายผล แต่พอเจอภาพเข้าไป แม่งยากกว่าเดิมเยอะ! เพราะรูปภาพหนึ่งรูปมันคือตัวเลขพิกเซลเยอะมากๆ ถ้าใช้ Neural Network แบบธรรมดา คอมพิวเตอร์คงสมองไหม้แน่ๆ

เลยต้องมี **CNN** เข้ามาช่วย ซึ่งมันแบ่งการทำงานหลักๆ เป็น 3 ขั้นตอน:

1. **Convolution Layer (สกัดฟีเจอร์):** 
   * เหมือนเอา "แว่นขยายอันเล็กๆ" (Filter) เลื่อนกวาดไปทั่วรูปภาพ
   * รอบแรกๆ มันจะเห็นแค่พวก **เส้นตรง, เส้นโค้ง, ขอบภาพ**
   * ยิ่งลึกขึ้น มันจะเริ่มผสมเส้นพวกนั้นจนเห็นเป็น **ตา, หู, จมูก, ล้อรถ**
2. **Pooling Layer (ย่อขนาด):**
   * รูปมันใหญ่เกินไป ประมวลผลช้า! เลยต้องทำการ Downsampling (หลักๆ ใช้ Max Pooling)
   * หยิบเฉพาะจุดที่เด่นที่สุดในแต่ละโซนออกมา รูปเลยเล็กลงแต่ยังคงรายละเอียดสำคัญไว้ได้
3. **Fully Connected Layer (ฟันธง):**
   * เอาฟีเจอร์ทั้งหมดที่สกัดได้ มารวมกันแล้วส่งให้ชั้นสุดท้ายทายว่า *"รูปนี้คือ แมว 95% / หมา 5%"*

> **สรุปสั้นๆ ให้ตัวเอง:** CNN = บีบรูปสกัดจุดเด่น -> ลดขนาดภาพ -> ทายว่าเป็นรูปอะไร

## 2. Object Detection - "ไม่ใช่แค่มองเห็น แต่ต้องชี้บอกตำแหน่งได้"

ตอนแรกฉันคิดว่า CNN ก็เก่งแล้วนะ แต่มันทำได้แค่ **Image Classification** (ทายว่าภาพนี้คือรูปอะไร)  
แต่ชีวิตจริง รูปมันไม่ได้มีแค่แมวตัวเดียวโดดๆ ไง! ถ้าในรูปมีทั้งคน รถ สุนัข พร้อมกันล่ะ?

นั่นเลยเป็นที่มาของ **Object Detection** ซึ่งทำ 2 อย่างพร้อมกัน:
* **Classification:** บอกว่าสิ่งนี้คืออะไร (Class)
* **Localization:** ตีกรอบสี่เหลี่ยม (Bounding Box) รอบสิ่งนั้นแล้วส่งค่าพิกัด $(x, y, w, h)$ ออกมา

## 3. โมเดลตัวท็อปที่ตอน ม.ปลาย สนใจมากๆ

* **YOLO (You Only Look Once):** 
  * โคตรเร็ว! มันมองรูปทีเดียวแล้วทำนายทั้งตำแหน่งและประเภทวัตถุพร้อมกันเลย
  * เหมาะมากกับงาน Real-time เช่น รถยนต์ไร้คนขับ หรือกล้องตรวจจับความเร็ว
* **Faster R-CNN:**
  * อันนี้จะช้ากว่า YOLO นิดหน่อย แต่ความแม่นยำคือจัดเต็ม! เหมาะกับงานที่ไม่รีบแต่ต้องการความชัวร์ เช่น ภาพถ่ายทางการแพทย์
